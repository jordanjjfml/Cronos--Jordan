# ⏱️ Cronos - Jordan

Um aplicativo de **cronômetro simples**, responsivo e intuitivo desenvolvido para a web. Este projeto foi criado com o objetivo de praticar conceitos fundamentais de desenvolvimento front-end, como manipulação do DOM e lógica de contagem de tempo com JavaScript.

## 🚀 Funcionalidades

* **Iniciar / Pausar:** Controle simples para dar play ou parar o tempo.
* **Resetar:** Zera a contagem e retorna o cronômetro para o estado inicial.
* **Interface Limpa:** Visual moderno focado na facilidade de uso.
* **Design Responsivo:** Adaptado para telas de computadores e dispositivos móveis.

## 📁 Estrutura do Projeto

O repositório está organizado da seguinte forma:

* `index.html` - Estrutura de marcação da página web.
* `style.css` - Estilização, layout e identidade visual.
* `script.js` - Lógica em JavaScript para controle do tempo (horas, minutos, segundos e milissegundos).
* `img/` - Pasta contendo imagens e ícones utilizados no projeto.

## 🛠️ Tecnologias Utilizadas

* **HTML5** – Estruturação do conteúdo.
* **CSS3** – Estilização e design responsivo.
* **JavaScript (ES6)** – Lógica do cronômetro e interatividade.

## 💻 Como Executar o Projeto

Para testar o cronômetro localmente em sua máquina, siga os passos abaixo:

1. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
2. Navegue até a pasta do projeto.
3. Abra o arquivo `index.html` em qualquer navegador web (Chrome, Firefox, Edge, etc.).
